# Sourmari — Android builds

Public download mirror for **Sourmari / سومري** preview APKs. Source code lives in a private repository; this repo holds only built, signed APK files.

**Latest build:** see [Releases](../../releases/latest).

Install: download `soumari.apk` on your Android phone, open it, allow installs from this source if asked. Every build is signed with the same key, so newer versions install over older ones without uninstalling.
